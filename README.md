 # Leveraged Funds and the Nasdaq-100 Close

Do leveraged funds move the Nasdaq-100’s last half hour?



A leveraged fund has to rebalance near the close every day. From yesterday’s fund assets and how far the index has moved by 3:30 pm, you can calculate how much each fund must buy or sell. That’s the formula from the demo page: assets × return × (L² − L), added up across the five funds.

Divide that total by the last half hour’s trading volume, so you know how big the forced trade is compared with normal trading.

Check whether days with a large predicted trade also show a larger price move between 3:30 and 4:00 pm, in the same direction.
